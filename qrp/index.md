# QRP & Homebrew Radio — A Resource Directory

*A growing, curated directory of QRP (low-power ham radio) and homebrew-electronics resources —
references, kits, schematics, articles, videos, parts sources, and notes worth keeping. Published
from Constellation `pages/qrp/` via GitHub Pages.*

*Maintained by AJ6YV. Started 2026-08-10.*

> **How this grows:** resources land here **each week during inbox processing** — when Bill emails
> himself a QRP link/idea (or one surfaces in the notes), it gets added here and the page is pushed.
> A living list, not a one-time build.
